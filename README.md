# C++ OOP Practical: Pointers, References & Dynamic Memory

## Aim

1. To implement pointers and references using student marks.
2. To implement dynamic memory allocation and deallocation using `new[]` and `delete[]`.

## Program A – Pointers and References

**File:** `pointers and references.cpp`

This program demonstrates:

* Pointer 
* Address of a variable
* Reference
* Updating student marks using pointer and reference

## Program B – Dynamic Memory

**File:** `dynamic memory using new and update operators.cpp`

This program demonstrates:

* Dynamic memory allocation using `new[]`
* Storing student marks
* Calculating total and average marks
* Releasing memory using `delete[]`
* Setting pointer to `nullptr`

## Concepts Used

* Pointers
* References
* Address operator `&`
* Dereferencing operator `*`
* Dynamic memory allocation
* `new[]`
* `delete[]`
* `nullptr`
